# 💊 Drug Recommendation System based on Sentiment Analysis of Drug Reviews

This project is a Machine Learning-based Drug Recommendation System that leverages sentiment analysis on drug reviews to suggest the most effective drugs for various medical conditions. By analyzing thousands of real-world patient reviews, the system aims to assist users in making better-informed decisions about their medication options.

## 📌 Features

- ✅ Sentiment analysis on drug reviews using NLP techniques
- 🧠 Machine Learning models for classification and recommendation
- 📊 Exploratory Data Analysis (EDA) and data visualization
- 💬 Review polarity detection (positive, neutral, negative)
- 📈 Drug ranking system based on aggregated sentiment scores
- 🏥 Condition-specific drug recommendations


- **Attributes include:**
  - Drug Name
  - Condition
  - Review
  - Rating
  - Useful Count
  - Sentiment Label (derived)

## 🧪 Tech Stack

- Python 🐍
- Pandas, NumPy
- Scikit-learn
- NLTK / SpaCy / TextBlob
- Matplotlib 


## 🛠️ How it Works

1. **Data Cleaning:** Handle missing values, remove stopwords, punctuation, and apply text normalization.
2. **Sentiment Analysis:** Perform sentiment classification using NLP models (e.g., Logistic Regression, Naive Bayes, or transformers).
3. **Model Training:** Train a sentiment classifier and a drug recommender model based on review scores and sentiments.
4. **Recommendation:** Given a medical condition, recommend top-rated drugs based on positive sentiments.
5. **Evaluation:** Use metrics like accuracy, precision, recall, and F1-score to evaluate model performance.
